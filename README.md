# API - Whatsapp Chatbot - Fake Analyser
## ⚙️ Configuração de ambiente:
Crie um arquivo `.env` na raiz do projeto e copie as variáveis abaixo preenchendo com as suas credenciais:

```properties
# Conexão com a Evolution API (WhatsApp)
OWN_API_URL = "http://localhost:8000"
EVOLUTION_API_URL=https://sua-evolution.com
AUTHENTICATION_API_KEY=seu_token_secreto_aqui
```
